# Chacota Polla Frontend V2

Frontend React + Vite para Chacota Polla Mundialista.

## Instalar

```bash
npm install
cp .env.example .env
npm run dev
```

## Backend

Configura:

```env
VITE_API_URL=https://chacota-polla-backend.jcmenesesq.workers.dev
```

## Usuario inicial

```txt
usuario: admin
password: Admin123*
```

## Funcionalidades

- Login por usuario.
- Registro de usuarios.
- Crear grupos.
- Unirse a grupo por código.
- Administrador de grupo puede aumentar cupo.
- Mapa del Mundial: grupos, fixture, fases.
- Predicciones por partido.
- Ranking por grupo.
- Panel admin para sincronización placeholder.
